# Caso 4 · Clientes

**Datos reales:** Online Retail II (ver caso 3). Solo se usan las facturas con cliente identificado; la parte excluida
se mide en el caso 5.

**Encuesta (siempre simulada, semilla 404):** una ola enviada a los clientes de los últimos 12 meses; responde 30 %.
Las notas dependen del tipo de cliente (por ejemplo, Campeones 62 % de promotores; En riesgo 46 % de detractores). Esa
relación es un supuesto del generador, por eso la página usa la encuesta para mostrar cómo calcular y leer la
recomendación, no para probar una relación.
